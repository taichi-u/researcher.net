# researcher.net

宇宙機の軌道設計・最適化に関する研究者の共著、指導、研究室、研究課題を調べる静的サイトです。HTML/CSS/JavaScript、Cytoscape.js、固定JSONで動作します。初版は研究者298人、論文5,186件、共著関係1,712件、指導関係25件を収録しています。

## 起動

Node.js 22以上を使用します。

```sh
npm ci
npm test
npm run validate
npm run build
npm run preview
```

ブラウザで `http://127.0.0.1:4173` を開きます。画面のデータは `site/data/dataset.json` に含まれ、起動時の外部APIやAPIキーは不要です。`dist/` は再ビルド時に置き換わる生成物です。

## 操作

- 共著ネットワークと研究の系譜を切り替えます。テーマ、出版年、関係の種類で絞り込めます。
- 氏名・別名・掲載時の所属・テーマ・論文名で検索できます。検索欄から下矢印で結果へ移動し、Enterで詳細を開けます。
- 人物を選ぶと概要、論文、関係、出典を表示します。関係から根拠論文または公式資料へ移動できます。
- 周辺表示の解除、全体表示、拡大縮小に対応しています。スマートフォンでは検索パネルと画面下の詳細パネルを使います。

## データの構成

| ファイル | 内容 |
| --- | --- |
| `site/data/seeds.json` | 本人確認した12名の起点と著者ID |
| `site/data/selected-authors.json` | 共著から抽出した候補と論文由来の所属 |
| `site/data/curation.json` | 公式資料で確認した人物・指導・研究室・研究課題 |
| `site/data/overrides.json` | 根拠付きID統合、除外、別名、手動訂正 |
| `site/data/review-queue.json` | 混合レコードなどの確認待ち |
| `site/data/crossref.json` | DOI照合用のCrossref登録情報19件 |
| `site/data/dataset.json` | ブラウザ表示用の固定データ |

所属履歴と各所属の根拠論文は人物内、論文の全著者・所属は論文内に保持します。指導などは独立した関係レコードで、出典URL・確認日・確認状態を持ちます。分野タグは根拠論文へ紐付きます。配置は生成時に計算され、絞り込みで再計算しません。

## 再取得・再生成

```sh
npm run collect -- all
npm run generate
npm run crossref
npm run generate
npm run validate
npm test
npm run benchmark
npm run build
```

`collect -- discover` は起点の候補調査のみ、`collect -- seeds` は起点の論文と共著候補まで取得します。原応答は `.cache/openalex/` と `.cache/crossref/`、収集途中の原レコードは `site/data/raw-*.json` に保持します。これらはGit対象外です。通信失敗や制限時はキャッシュを再利用して同じコマンドで再開できます。収集中の状態では新しい表示データを生成しません。

必要な場合のみ `OPENALEX_API_KEY` を収集時の環境変数に指定します。キーはブラウザや保存URLに含めません。初版は2026年10月23日までの固定スナップショットです。更新時は収集・生成スクリプトの調査日と対象日を変更し、キャッシュを新しい調査用ディレクトリへ退避してから再収集してください。自動更新・スケジュールは設定していません。

訂正は `overrides.json`、公式根拠の追加は `curation.json` に保存します。自動取得の結果を直接書き換えません。名前だけの統合は禁止し、公式の和英表記、ORCID、所属、共著論文を照合します。DOIのない公式会議記録も、OpenAlex互換の形式で `additionalWorks` に追加できます。`curatedIdentities` は公式資料の人物と論文側のIDを確認した対応表です。

## 対象範囲と限界

12名の起点から2件以上の対象論文でつながる共著者を順に選び、選んだ人物の対象論文を追加取得しています。起点以外の人物同士の共著も集計します。50名を超える著者の論文は初版の集計対象外です。全世界の網羅的な名簿ではなく、大学および米国・日本・欧州・中国の研究者が多い標本です。企業・研究機関も含みます。

テーマは題名・公開要旨のキーワードによる分類です。原データの著者抜けや取り違え、DOIがない重複レコード、所属の欠落などが残る可能性があります。OpenAlexの別名には別人が混入する例があったため、自動収録せず確認済みの別名を使います。Crossrefは19件の補助照合に使用しており、全論文の二重検証を意味しません。

論文の掲載時所属を現在所属として扱いません。研究課題の実施期間を参加者個人の在籍期間とは扱いません。指導関係を共著や同研究室から推定しません。年代不明を埋めずに残します。共著数は収録データ内の数値です。

## デザインと検証

[デザイン調査](site/data/design-research.md)に参考サイト、配色、書体、形状の判断と出典を記録しています。薄い罫線で検索・マップ・詳細を分け、色はテーマ、形は人物・研究室・課題、線種は関係に割り当てています。装飾的な宣伝文や詩的なコピーは置いていません。

`npm test` は年・分野の連動集計、年代不明、共同指導、同姓同名、別名、所属、DOI重複、手動訂正の保持を検証します。`npm run benchmark` は公開データを変えずに400人の検証用標本で検索・集計を測定します。測定値は `site/qa/performance.json` に保存され、ブラウザの描画時間は含みません。`node site/scripts/prepare-browser-qa.mjs` は390px表示と400人のローカル検証画面を生成します。検証後は `npm run build` を再実行して検証用ファイルを除去してください。実測値とブラウザ検証範囲は [検証記録](site/qa/browser-verification.md) に記録しています。

## ホスト

`.openai/hosting.json` はChatGPT Sitesの本人限定サイトを指定します。Sitesのソース同期にはSites専用のリポジトリURLを使い、GitHubの `origin` は変更しません。Sitesへの公開には公式Sitesワークフローを使用してください。
