# 初版の検証記録

実施日: 2026-10-23〜24。データの対象日は2026-10-23。
環境: macOS arm64、Chrome（Workプロファイル）、Node.js v22.14.0。

## データ・自動検証

- 298人、5,186論文、1,712共著関係、25指導関係、3研究室、2研究課題。
- 10件の自動テスト成功。年代とテーマの連動、年代不明、共同指導、同姓同名、別名と所属検索、DOI重複、手動訂正の保持、1次近傍、和英著者IDの統合を検証。
- 参照ID、DOI一意性、出典URL、座標、指導関係の非循環性、収集完了状態を検証。
- 公式資料との照合が不十分な著者候補は確認待ちへ分離。全論文の著者・所属を人手で再検証したものではない。

## ブラウザ操作

- 日本語別名「尾崎直哉」で1人を検索し、詳細と周辺関係、共著論文へ移動。
- 共著論文のDOIからSpringerの掲載ページを開き、著者・出版年・DOIを確認。対象DOI: `10.1007/s40295-021-00299-4`。
- 2020〜2026年・低推力テーマ: 117人、207共著関係、383論文。独立した集計結果と画面が一致。尾崎直哉の一覧・詳細・論文タブはいずれも6件で、掲載年は2020〜2025年。
- 系譜表示: 26人、25指導関係。階層配置、矢印、ラベル折り返しを画面確認。Howell→Bosanacの詳細で2016年博士指導と本人CVへのリンクを確認。
- ノードhoverで氏名・所属年・複数テーマを確認。
- 幅390px・高さ844pxのiframe内でレスポンシブ表示を確認。検索からEnterで詳細を開き、下部パネルを表示。横はみ出しなし。検索結果0件の状態も確認。
- 確認時のブラウザコンソールにアプリのエラーなし。

モバイル実機のタッチ操作、OSスクリーンリーダー、全ブラウザの組合せは未検証。ネイティブChrome操作では一時的な操作接続の遅延があり、復帰後はタブに固定して検証した。

## 400人の処理性能

公開JSONを変更せず、102人の検証用レコードと対応論文を追加した400人のローカル画面を使用。実在人物数として公表するデータには含めない。

| 操作 | 更新処理時間 |
| --- | ---: |
| 初期表示 | 277.5 ms |
| 低推力テーマへ変更 | 105.1 ms |
| 絞り込みを全解除 | 169.1 ms |
| 全体で論文・テーマ語を検索 | 63.9 ms |
| 年代とテーマの複合条件 | 223.1 ms |

ブラウザの`performance.now()`でモデル計算、DOM生成、Cytoscape更新呼び出しまでを計測。検索の入力待機80ms、年代入力待機120ms、ネットワーク読み込み、最終ピクセルの描画完了は含まない。検証時に500msを超えた更新は、不要な色変更の抑制と要素の差分更新で改善した。モデル単体の別測定は`performance.json`参照。

## 再現

```sh
npm test
npm run validate
npm run benchmark
npm run build
node site/scripts/prepare-browser-qa.mjs
npm run preview
```

`/mobile-qa.html` と `/performance-qa.html` が検証専用画面。公開前に再度`npm run build`を実行し、これらと検証用データを削除したビルドを作る。
