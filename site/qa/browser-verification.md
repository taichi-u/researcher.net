50回のズーム・pan更新に対して、毎回requestAnimationFrameを1回待つ同じ手順で比較した。更新間隔はJavaScriptの処理とブラウザのフレーム待ちを含む。GPUの描画完了を直接測定した値、実機での60fps保証、統計的な平均ではない。単発の計測値であり、実行環境に依存する。初期JSONの削減率は約67%。追加フォントは76,260 Bで、論文詳細は必要時の別通信。

### 確認した操作

- 氏名ラベルの、点から離れた文字部分をマウスでクリックして人物詳細へ移動。
- 人物選択時、全77共著関係を追加して強調。薄い線の実際の中点をクリックしても人物選択を維持。強調線の実クリックは共著論文の詳細へ移動。
- 無関係な線のeventsはno、強調線はyes。解除後に通常の線の操作へ復帰。
- 「主要な線」から「すべての線」で1,704本へ切り替え。検索や総数は描画を省略しても変わらない。
- 初期表示・人物概要・論文一覧までは詳細JSONの通信0件。「全著者・掲載時の所属」を開いた時点で1分割を取得し、閉じて開き直しても追加通信なし。
- 低推力・2020〜2026年の条件で117人、207共著関係、383論文。0件検索とクリア、研究の系譜への切り替え。
- 幅390px・高さ844pxのタッチ設定で検索パネル、別名「尾崎直哉」、Enterによる選択、下部詳細、閉じる操作。横はみ出しなし。詳細を開いた地図の高さは約178px。自動表示の余白を地図サイズに合わせ、点や名前が一時的に巨大化する問題も修正。
- Source Serif 4と日本語見出し、長い所属、選択状態をスクリーンショットで確認。フォントのCanvas指定で数字入りの書体名に引用符が必要な点を修正。
- 最終実行でアプリのpageerrorなし。

### 検証の範囲

自動テスト13件、データ検証、ビルド、Chrome/CDPでの操作検証を実行。論文の元レコードと分割を比較し、集計・検索・著者所属が維持されること、同一分割の同時要求共有、失敗後の再試行もテストした。

ブラウザ検証の途中でモバイル初期化の待機タイムアウトが1回発生。診断ログを追加した再試行と400人の実行は成功し、再現しなかった。原因は未特定。モバイル実機、Safari・Firefox、OSスクリーンリーダー、低速回線の組合せは未検証。「全線」表示や非常に大きな将来データには追加の計測が必要。

### 再現手順

ChromeとPlaywrightが利用できる環境で、プレビューを起動してから実行する。Playwrightをローカル依存に追加していない環境では、RESEARCHER_QA_PLAYWRIGHTに利用可能なindex.mjsの絶対パスを指定する。

```sh
npm test
npm run validate
npm run build
node site/scripts/prepare-browser-qa.mjs
npm run preview
# 別のターミナル
npm run test:browser
RESEARCHER_QA_URL=http://127.0.0.1:4173/qa400/index.html RESEARCHER_QA_OUTPUT=.cache/browser-qa400 npm run test:browser
# 公開前には検証用ファイルを除く
npm run build
```

ローカルの詳細なスクリーンショットとreport.jsonは.cache/browser-qa/と.cache/browser-qa400/に保存される。Git・公開物には含めない。比較値は[browser-performance.json](browser-performance.json)に保存。

## データ・自動検証

- 296人、5,186論文、1,704共著関係、25指導関係、3研究室、2研究課題。
- 10件の自動テスト成功。年代とテーマの連動、年代不明、共同指導、同姓同名、別名と所属検索、DOI重複、手動訂正の保持、1次近傍、和英著者IDの統合を検証。
- 参照ID、DOI一意性、出典URL、座標、指導関係の非循環性、収集完了状態を検証。
- 公式資料との照合が不十分な著者候補は確認待ちへ分離。全論文の著者・所属を人手で再検証したものではない。
- 最終名寄せでG. Radice / Gianmarco Radice、M. W. Lo / Martin W. Loを公式業績と原論文で照合・統合。298人から296人に補正し、再生成と検証を実施。

## ブラウザ操作

- 日本語別名「尾崎直哉」で1人を検索し、詳細と周辺関係、共著論文へ移動。
- 共著論文のDOIからSpringerの掲載ページを開き、著者・出版年・DOIを確認。対象DOI: `10.1007/s40295-021-00299-4`。
- 2020〜2026年・低推力テーマ: 117人、207共著関係、383論文。独立した集計結果と画面が一致。尾崎直哉の一覧・詳細・論文タブはいずれも6件で、掲載年は2020〜2025年。
- 系譜表示: 26人、25指導関係。階層配置、矢印、ラベル折り返しを画面確認。Howell→Bosanacの詳細で2016年博士指導と本人CVへのリンクを確認。
- ノードhoverで氏名・所属年・複数テーマを確認。
- 幅390px・高さ844pxのiframe内でレスポンシブ表示を確認。検索からEnterで詳細を開き、下部パネルを表示。横はみ出しなし。検索結果0件の状態も確認。
- 確認時のブラウザコンソールにアプリのエラーなし。

モバイル実機のタッチ操作、OSスクリーンリーダー、全ブラウザの組合せは未検証。ネイティブChrome操作では一時的な操作接続の遅延があり、復帰後はタブに固定して検証した。
